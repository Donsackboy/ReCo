# Cómo convertir un usuario en superusuario y staff desde Django shell

1. Abre el shell de Django dentro del contenedor:
	docker-compose exec backend python manage.py shell

2. Ejecuta lo siguiente:

from registry.models import Usuario
u = Usuario.objects.get(username='adminreco')
u.is_superuser = True
u.is_staff = True
u.save()

Esto convertirá el usuario en superusuario y staff si no lo es.
